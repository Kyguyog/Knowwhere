How to Use Idle Breakout Save Editor

  1. Open Idle Breakout on Hoodamath and go to Settings → Export
  2. Copy your save code and paste it in the box at the top
  3. It will automatically decode and show your save values below
  4. Click "Lock Data for Editing" to enable editing
  5. Add labels to values so you know what they do either manually or via a .json file
  6. You can go to my Github to get the latest JSON file
  7. Click "Edit" next to any value to modify it
  8. When done, click Copy Base64
  9. Import the text in your clipboard into Idle Breakout Settings → Export
